# Currency-Convertor
The currency convertor will be made in Java. The first version will use hardcoded values and the second part will be linking an API with real time exchange values to make a accurate Currency Convertor. 3rd stage may include a way to save and invest money for fun.

In the release contains the .jar file. Use this to run the code.
